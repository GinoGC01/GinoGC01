## Proyectos Destacados

### [Leads-Pro - Motor de Orquestación B2B](https://github.com/GinoGC01/leads-pro-ai)
Pipeline LLM multi-agente para prospección automatizada y calificación técnica de leads. Web scraping headless, base de datos vectorial Qdrant, integración con OpenAI API y automatización vía webhooks. Incluye pipelines de datos con OCR y visión artificial.

### [AuditAI - Análisis de Resúmenes Bancarios](https://auditai.ginociancia.fun)
Sistema backend para análisis automatizado de resúmenes bancarios con IA. Sistema RAG con base vectorial, integración con APIs de IA y Telegram. Arquitectura de microservicios.

### [Cancha Libre - Gestión de Ligas de Fútbol Amateur](https://github.com/GinoGC01/gastos-backend)
Aplicación fullstack para la gestión de torneos, fixtures, equipos y estadísticas de ligas amateurs. Backend Node.js/TypeScript con base de datos relacional, frontend React con foco en UX mobile-first para dirigentes y jugadores.

### [HackDental - Plataforma de Captación de Pacientes](https://github.com/GinoGC01)
Arquitectura full-stack con Node.js, TypeScript y Supabase. Frontend completo en React + Tailwind. Integración de servicios externos, sincronización de datos y automatización de flujos.

### [La Promesa Deportes - Sitio Corporativo](https://la-promesa.vercel.app)
Sitio institucional para empresa manufacturera de indumentaria deportiva. Stack: Astro + Tailwind CSS. Catálogo dinámico vía Google Sheets API. Diseño mobile-first. Proyecto en producción (beta).
